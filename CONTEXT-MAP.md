# Context Map

This is a multi-context repo. Domain documentation is split across:

| Context | File | Scope |
| ------- | ---- | ----- |
| Shared / system-wide | [`CONTEXT.md`](./CONTEXT.md) | Terms that span both backend and frontend |
| Backend | [`backend/CONTEXT.md`](./backend/CONTEXT.md) | Data models, API conventions, flowchart inference logic |
| Frontend | [`frontend/CONTEXT.md`](./frontend/CONTEXT.md) | UI components, session state, upload flow |

Read the shared glossary first, then the context-specific file for the area you're working in.
