HOW TO ADD A NEW MAJOR
======================

Tell Claude: "Add [MAJOR NAME] to the flowchart system. Follow the steps in add-major-steps.txt."

Claude will:

1. Fetch the catalog page from catalog.calpoly.edu and extract every course
   with: course number, title, units, term (Freshman Fall -> Senior Spring),
   and whether it's a major requirement, support course, or GE.

2. Add [CODE]_FLOWCHART in backend/data/flowcharts.py:
   - Prefix all IDs with [CODE]_ to avoid collisions with other majors
   - grid_col 0-7 (Freshman Fall=0, Senior Spring=7), grid_row can be 0
     everywhere since _compact_rows_by_category handles it
   - category: "major", "support", "ge", or "concentration"
     (use "concentration" for free/unrestricted electives)
   - is_placeholder: True for any elective slot, GE area, or placeholder
   - prerequisites: add where the prereq course exists in the same
     flowchart -- use semester course number strings (e.g. ["AGB 2212"])
   - quarter_equivalents: prioritize mappings for every direct semester
     course where one exists -- many student transcripts still use quarter
     numbers

3. Call _compact_rows_by_category([CODE]_FLOWCHART) in the block near
   the bottom of flowcharts.py.

4. Add an entry to the FLOWCHARTS dict at the bottom of flowcharts.py.

5. If the major has concentrations/emphases/tracks, add them to
   backend/data/concentrations.py following the existing pattern.

6. Add a major-specific test in backend/tests/test_flowchart_data.py
   that checks: total_units, key course titles, categories, at least 2
   prerequisites, GE placeholders, elective placeholder is_placeholder,
   and whether the major is/isn't in CONCENTRATIONS.

7. Run pytest from the backend directory using .venv and confirm all
   tests pass.

8. Do not commit or push when done.

9. Report any catalog ambiguities or elective buckets represented as
   placeholders.


HOW TO AUDIT AND FIX SUPPORT/ELECTIVE COURSES AGAINST THE CATALOG
==================================================================

Use this when a course appears in the flowchart or elective picker that
doesn't exist in the semester catalog (e.g. "BIO 111" instead of "BIO 1111").

Step 1 — Identify which courses are wrong
  Run this in the backend (.venv activated) to see every real course in a
  department:

      python3 -c "
      from services.catalog import get_dept_courses
      for cn, info in sorted(get_dept_courses('bio').items()):
          print(cn, info['title'])
      "

  Repeat for each relevant department (e.g. 'bot', 'zoo', 'mcro', 'math').
  Any course number in the flowchart or elective list that doesn't appear
  in this output is wrong and needs to be fixed.

Step 2 — Fix the static elective list in electives.py
  Find the relevant key in _STATIC (e.g. "cs_life_science") and:
    - Remove course numbers that don't exist in the semester catalog
    - Add any catalog courses that are missing
    - Correct wrong course numbers (e.g. BOT 1111 -> BOT 1121)
    - Correct wrong titles to match what get_dept_courses() returns

Step 3 — Fix the auto-picker if it exposes quarter-system numbers
  The /auto/placeholder endpoint parses course_number + quarter_equivalents
  to build a course list. If that exposes old quarter numbers (e.g. BIO 111),
  add the placeholder's id to _PLACEHOLDER_ELECTIVE_KEY in electives.py:

      _PLACEHOLDER_ELECTIVE_KEY: dict[str, str] = {
          "LIFESCI": "cs_life_science",   # <- add entry like this
      }

  This makes the endpoint use the clean static list instead of parsing
  raw quarter_equivalents.

Step 4 — Update quarter_equivalents in flowcharts.py
  The quarter_equivalents list on each placeholder serves TWO purposes:
    a) inference: marks the slot complete when a transcript shows that number
    b) legacy mapping: maps old quarter course numbers for returning students
  After fixing the catalog-facing list, also update quarter_equivalents to
  include every valid SEMESTER course number so inference works for students
  who took the correct semester course. Keep old quarter numbers (e.g.
  "BIO 111") in the list — they don't appear in the picker, only in inference.

  Example for LIFESCI after fix:
      "quarter_equivalents": [
          "BIO 111",                     # quarter legacy (kept for inference)
          "BIO 1111", "BIO 1150",        # valid semester options
          "BIO 1151", "BOT 1121",
          "MCRO 2221"
      ]

Step 5 — Run tests
  cd backend && source .venv/bin/activate && python3 -m pytest tests/ -q
  All tests must pass before committing.
